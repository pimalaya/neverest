# A create is named by what delivers it

The report gained an `Add` hunk and an `origin` on `Copy`. A create a frontend queued on a side syncing alone reads `add item … on <side>`, a move or a copy the server makes in place reads `copy item … from <origin> to <collection> on <side>`, and only a body the other side holds is still a copy across. Verified with a dry run over a card cardamum queued against the fastmail replica.
