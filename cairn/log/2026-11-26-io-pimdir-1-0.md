# io-pimdir 1.0: pimdir v1

neverest moves to io-pimdir 1.0.0, which follows pimdir storage-v1.0.0, sync-v1.0.0 and search-v1.0.0. Cargo.toml asks for `version = "1.0.0"`, from crates.io. A store any draft wrote (every 0.x io-pimdir, every neverest before 1.0.0) is refused as `store-version`, never migrated: sync it with the neverest that wrote it until nothing is queued, move the store directory aside, then `neverest sync --init`. An index of a search draft is rebuilt.

## What landed

- Cargo.toml, Cargo.lock: io-pimdir 0.20.4 to 1.0.0, features unchanged.
- src/sync/driver.rs: `PimdirRunError` imported from `client::run`; `open_store` maps the `Result` `PimdirStore::for_source` now returns (an empty source id, `source-empty`, which neverest never binds) into the store's coded error. `written_earlier` reads io-pimdir's order unchanged: no version, a draft or an earlier release is an earlier neverest's, a later release or an unread marker a newer one's.
- src/conflict.rs: the settled conflict's source handle maps the same `Result`.
- Tests: every `for_source` in test code unwraps. src/sync/driver/tests.rs `a_store_version_tells_an_earlier_neverest_from_a_newer_one` names draft-17 and draft-18 earlier and `storage-v2` later; `a_store_a_newer_neverest_wrote_asks_for_an_upgrade` and tests/queue.rs `a_store_a_newer_neverest_wrote_fails_with_its_code` stamp `storage-v2`, a draft now being earlier; src/sync/index.rs `an_index_of_a_later_release_is_refused_and_left` stamps `search-v2`. `a_moved_card_is_itemized_as_both_its_halves` registers its source on the target (`PimdirSourceStore::register`): io-pimdir 1.0 refuses a move into a collection no source syncs (`PimdirMutateError::Unsynced`).
- No other 1.0 break reached neverest: it names no `PimdirSearchCursor`, `PimdirSearchSort`, `Chunks`, `load::PimdirRefusal`, `PimdirQueryErrorCode`, `PimdirQueryDateRange` nor `FORMAT_DRAFT`, and matches no `PimdirMutateError` exhaustively. Its only `mutate` is the one-way overwrite's `Edit`, which no `Unsynced` refusal meets; a frontend's queued move or copy into a collection no source syncs is the store's to park.

## Spec

[sync](../spec/sync.md): the header names storage-v1.0.0, sync-v1.0.0 and search-v1.0.0; *A store the format outgrew is refused with its remedy* counts a draft as earlier; *A store a newer neverest wrote asks for an upgrade* names a later release, its `--json` scenario `storage-v2`; `source-empty` joins the codes neverest cannot meet.
